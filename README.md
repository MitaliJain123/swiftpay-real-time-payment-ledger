# SwiftPay - Real-Time Payment Ledger

SwiftPay is a real-time peer-to-peer payment ledger system built using Java and Spring Boot.

## Current Architecture

The project is being developed as a microservice-based application.

### Services

- Transaction Gateway
- Ledger Service
- Analytics Worker (Bonus)

## Technology Stack

- Java 21
- Spring Boot
- PostgreSQL
- Apache Kafka
- Redis
- Docker
- Swagger / OpenAPI
- GitHub Actions

## Current Progress

### Transaction Gateway
